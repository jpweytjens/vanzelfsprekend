# How-to

*Each page answers one question.*

| I want to | Use |
|---|---|
| End the spines at the data, not at a round number | `frame="data"` on [frame modes](frame-modes.md) |
| Move the axis label to the spine's end | [axis labels](axis-labels.md) |
| Name each line without a legend | `line_labels` on [direct labels](direct-labels.md) |
| Label one point inside the plot | `label` on [direct labels](direct-labels.md) |
| Put a tick at a value that matters, a threshold or a peak | `FeatureLocator` on [locators](locators.md) |
| Keep the round-number ticks and add your own | `AugmentedLocator` on [locators](locators.md) |
| Draw attention to that tick | `accent` on [accent](accent.md) |
| Get fewer or more ticks | `spacing` and `n` on [tick spacing](tick-spacing.md) |
| Put the unit or a common factor on the ticks | [tick formats](tick-formats.md) |
| Count in π or another step | `TalbotLocator(unit=)` on [non-decimal ticks](radian-axes.md) |
| Show the same axis in another unit | `secondary_frame` on [non-decimal ticks](radian-axes.md) |
| Use colour only where it means something | [colour](colour.md) |
| Frame a grid of panels on one scale | `small_multiples` on [small multiples](small-multiples.md) |
| Undo everything | [restore](restore.md) |
